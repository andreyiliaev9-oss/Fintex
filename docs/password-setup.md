# Пароли и PIN удалены

По просьбе владельца вход по паролю/PIN, блокировка приложения и восстановление через бота удалены. Приложение открывается сразу, в том числе без сети. Прежние флаги `fp_auth_required` и `fp_auth_lock_event` не используются; финансовые данные и очередь синхронизации не очищаются.

## Облако — отдельно от открытия приложения

`cloud.js` отправляет подписанные Telegram `initData` вместе с обычными запросами синхронизации. Сервер проверяет подпись, срок и UID. Запросы только с UID или ключом iOS не могут читать данные. API паролей, PIN, OTP и сессий удалён. Сам Telegram остаётся средством подтверждения учётной записи для облака, но не блокирует локальный интерфейс.

Для облачной синхронизации нужен сервер v6: замените целиком существующий `Code.gs` файлом `downloads/Fintex-Code.txt` и опубликуйте новую версию того же развёртывания. Альтернатива для нескольких файлов — `backend/Code.gs` + `backend/Auth.gs`, без дублей функций. Старый `PasswordKdf.gs` больше не используется и может быть удалён из проекта. Таблицу и секреты менять не нужно. Без обновления сервера приложение всё равно открывается, но синхронизация со старым сервером может не работать.

Листы и старые записи `Auth` не удаляются. Нет запроса пароля и нет писем/сообщений сброса. Действующие ключи iOS сохраняются; они по-прежнему разрешают только добавление операций, а не чтение. Локальные данные браузера не зашифрованы; человек с доступом к этому профилю браузера может их увидеть. Защитите сам телефон и Telegram.
