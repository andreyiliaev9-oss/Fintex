# Map libraries

- Leaflet 1.9.4 — https://github.com/Leaflet/Leaflet — BSD-2-Clause (LEAFLET-LICENSE.txt).
- Leaflet.heat 0.2.0 — https://github.com/Leaflet/Leaflet.heat — BSD-2-Clause (LEAFLET-HEAT-LICENSE.txt); includes simpleheat.

Pinned npm distributions, no CDN execution. Leaflet CSS/license line endings normalized to LF; trailing whitespace removed. Street tiles are fetched by the browser only after explicit session consent from https://tile.openstreetmap.org. © OpenStreetMap contributors, ODbL: https://www.openstreetmap.org/copyright. No tile prefetch, bulk download, offline caching or geocoding. Public tile service is best-effort and not a production SLA; review usage policy before scale: https://operations.osmfoundation.org/policies/tiles/ .
