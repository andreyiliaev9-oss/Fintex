Filely — исправление отображения финансового дерева

Заменить в корне GitHub-репозитория только index.html и financial_tree.js.
Оба файла должны находиться в одной папке (корне репозитория).
Остальные файлы не менять.

В этой версии модуль сам создаёт контейнер дерева, если его нет, и повторно
монтирует карточку, если приложение удалит её при перерисовке главного экрана.
