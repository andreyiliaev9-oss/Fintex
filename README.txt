FILELY — ТЕКУЩАЯ СБОРКА ПРОЕКТА

Архив содержит полную сборку проекта на основе последнего комплекта Filely-fixed,
обновлённую главную страницу с финансовым деревом, модуль дерева и его изображение.

УСТАНОВКА
1. Распакуйте архив.
2. Загрузите ВСЕ файлы из папки Filely-current-project в корень GitHub-репозитория.
3. Подтвердите замену файлов с совпадающими именами.
4. Не загружайте саму папку Filely-current-project как вложенную папку — нужны файлы внутри неё.
5. Не удаляйте настройки GitHub Pages и другие служебные файлы репозитория.

Финансовое дерево подключено через financial_tree.js и использует financial_tree_art.png.

Проверки: все локальные JS-файлы, подключённые в index.html, присутствуют; синтаксис всех JS-файлов проверен.
Полноценный запуск в браузере/на устройстве в этой среде не подтверждён.
