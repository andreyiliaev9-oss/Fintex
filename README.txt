FILELY — ПАТЧ «МОЁ ФИНАНСОВОЕ ДЕРЕВО»

Изменены только два файла:
1. index.html — добавлен слот для дерева и подключение нового модуля.
2. financial_tree.js — новый независимый модуль визуализации дерева.

Установка:
- Заменить index.html в корне GitHub-репозитория.
- Добавить financial_tree.js в корень репозитория.
- Остальные файлы не менять.

Данные:
- fp_goal: сохранённая сумма и цель накоплений.
- fp_local_tx: операции за последние 30 дней.
Модуль только читает эти данные и не изменяет баланс, цели или операции.
